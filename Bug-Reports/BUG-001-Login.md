# BUG-001 — Login button does not work with valid credentials

## Bug Summary

The Login button does not work when valid credentials are entered.

## Steps to Reproduce

1. Open the login page.
2. Enter a valid username.
3. Enter a valid password.
4. Click the Login button.

## Expected Result

The user should log in successfully and be redirected to the Products page.

## Actual Result

Nothing happens after clicking the Login button.
