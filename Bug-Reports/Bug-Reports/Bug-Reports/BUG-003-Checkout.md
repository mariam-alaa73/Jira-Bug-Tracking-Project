# BUG-003 — Checkout button is disabled after adding a product to cart

## Bug Summary

The Checkout button is disabled after adding a product to the cart.

## Steps to Reproduce

1. Open the Products page.
2. Add any product to the cart.
3. Open the Cart.
4. Click Checkout.

## Expected Result

The Checkout button should be enabled and allow the user to proceed to the checkout page.

## Actual Result

The Checkout button is disabled and the user cannot proceed.
