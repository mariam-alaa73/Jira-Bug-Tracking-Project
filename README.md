# Jira Bug Tracking Project

## About the Project

This is a QA practice project that I created to practice bug reporting and bug tracking using Jira.

I worked on different bugs and followed them through the bug life cycle.

## Tools Used

- Jira
- GitHub

## What I Practiced

- Creating bug reports
- Writing steps to reproduce
- Writing expected and actual results
- Setting Priority
- Setting Severity
- Assigning bugs
- Adding labels
- Changing bug status
- Retesting bugs
- Using Jira Board and Dashboard

## Bug Life Cycle

I used the following workflow:

To Do → In Progress → Done

## Bugs

| Bug ID | Description                                                            | Priority | Severity | Status |
| ------ | ---------------------------------------------------------------------- | -------- | -------- | ------ |
| KAN-6  | Login button does not work with valid credentials                      | High     | High     | To Do  |
| KAN-7  | Product image is not displayed on product details page                 | Medium   | Medium   | Done   |
| KAN-8  | Checkout button is disabled after adding a product to cart             | High     | High     | Done   |
| KAN-9  | Cart quantity is not updated after changing the product quantity       | Medium   | Medium | PRRPROGRESS  |
| KAN-10 | Checkout allows user to continue without required customer information | High     | High     | INPROGRESS  |


## Bug Report Example

Each bug contains:

- Summary
- Steps to Reproduce
- Expected Result
- Actual Result
- Priority
- Severity
- Label
- Assignee
- Status

## Jira Dashboard

I also created a Jira dashboard to track the bugs and their current status.

## What I Learned

Through this project, I practiced how to report bugs clearly and how to track them from the moment they are reported until they are completed.
